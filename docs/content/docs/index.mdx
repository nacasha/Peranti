**Peranti** is a cross-platform desktop application with a collection of small tools that help developers with
common tasks: format or minify JSON, convert timestamps, encode or decode text, generate hashes, and many more.

It is completely offline, collects no data, and is free and open source.

![Peranti](/screenshots/peranti.png)

## Why Peranti?

- **Private by default** — every tool runs on your machine. Nothing you paste leaves it.
- **Many tools, one window** — open tools in tabs and keep their data while you switch between them.
- **Batch mode** — run a tool over many inputs at once, one per line.
- **Extensible** — add your own tools in JavaScript or any language with [extensions](/docs/extensions).
