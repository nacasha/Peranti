Peranti ships with these tools. You can add more with [extensions](/docs/extensions).

| Category | Tools |
| --- | --- |
| CSV | CSV Column Reorder, CSV Table Viewer |
| Color | Color Converter, Color Extract, Color Pallete Generator, Tints And Shades Generator |
| Date & Time | CRON Parser, Date ↔ Milliseconds |
| Diagram | Mermaid Diagram, Pintora Diagram |
| Editor | Markdown Editor, Text Editor |
| Encoding | Base64 Encode / Decode, URI Encode / Decode, Base64 ↔ File |
| Generator | Random String, UUID, Hash, Lorem Ipsum |
| Web | Favicon Grabber |
| JSON | Compare / Diff, Formatter, Table Viewer, JSON ↔ CSV, JSON ↔ TOML, JSON ↔ YAML, JSONata |
| Code | Javascript Runner, React Runner, Math Evaluator |
| List | Compare List, Prefix Suffix List, Remove Duplicate List, Sort List |
| SQL | SQL Formatter, SQL Minify, SQL Where Query |
| Text | Text Case Transform, Text Counter, Text Escape / Unescape |
